# CUTE-RONOVA

A cute little fan-made tribute to Ronova from Genshin Impact.

## Tech Stack

- **React 19**
- **Vite**
- **React Router**
- **Cloudflare Workers** (Static Assets)

## Development

```bash
npm install
npm run dev
```

## Production Build & Deploy

```bash
npm run build
npx wrangler deploy
```
